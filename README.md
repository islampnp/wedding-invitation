# دعوة زفاف — Wedding Invitation

A digital wedding invitation card (Arabic, RTL) built as a single static HTML page.

- **Live page:** https://islampnp.github.io/wedding-invitation/
- No build step, no dependencies — just `index.html`.
- Fonts are loaded from Google Fonts (Amiri, Aref Ruqaa, Cairo).

## Local preview

Open `index.html` in any browser, or:

```bash
python -m http.server 8000
# then visit http://localhost:8000/
```
